Buddy 2: Motion Control System
Primary hardware: Motors + wheel encoders
Core work
Integrate motor drivers and encoders
Estimate speed and distance
Tune PID speed control
Correct straight motion and execute turns
Expected deliverables
Motion-control library
PID tuning report
Motion accuracy evaluation

Buddy 4: IMU-Based Motion and Terrain Monitoring
Primary hardware: IMU
Core work
Calibrate the IMU
Detect tilt, humps and peak height
Classify motion and detect collision
Report turn rate and motion events
Expected deliverables
IMU processing module
Hump-detection algorithm
Terrain analysis report

E M B E D D E D  S Y S T E M S  P R O J E C T STUDENT BRIEFING
Buddy 5: Adaptive Ultrasonic Scanning and Obstacle Profiling
Primary hardware: Ultrasonic sensor + servo
Core work
Coarse scan, then fine scan around obstacles
Estimate location, width and clearance
Plan stop, turn or reverse actions
Recover and reacquire the original line
Expected deliverables
Scanning subsystem
Obstacle profile generator
Avoidance and recovery algorithms
